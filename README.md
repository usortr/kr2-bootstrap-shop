# Контрольная работа №2: CSS-фреймворки

## Описание
Проект представляет собой учебный маркетплейс «SpruceMarket», разработанный с использованием фреймворка **Bootstrap 5**. Целью работы было создание современного, отзывчивого интерфейса, максимально приближенного к UX популярных маркетплейсов (Ozon, Wildberries), с сохранением всех требований дисциплины.

## Используемые технологии
- HTML5 (семантическая разметка, ARIA-атрибуты)
- Bootstrap 5.3 (CDN)
- Bootstrap Icons
- CSS Grid / Flexbox, CSS-переменные (тема)
- БЭМ для собственных блоков поверх Bootstrap
- Vanilla JavaScript (валидация, DOM-манипуляции, `localStorage`)
- Git, GitHub, GitHub Pages

## Структура проекта
- `index.html` — главная страница с hero-блоком и хитами продаж
- `catalog.html` — каталог с липкими фильтрами и сеткой товаров
- `product.html` — детальная карточка товара: характеристики, похожие товары, отзывы
- `order.html` — корзина и оформление заказа
- `contacts.html` — контакты, форма обратной связи и FAQ
- `css/custom.css` — доработки стилей поверх Bootstrap (БЭМ-блоки, тёмная тема)
- `js/products.js` — каталог товаров (50 позиций, 5 категорий) и функции доступа к данным
- `js/cart.js` — корзина на `localStorage` (добавление, изменение количества, подсчёт суммы)
- `js/main.js` — рендеринг карточек, фильтры, валидация, модальные окна, кнопка «Наверх», рейтинг и чипсы

## Самостоятельные доработки
1. Собственная визуальная концепция: тёмная тема, единая палитра через CSS-переменные, переопределение переменных Bootstrap
2. Расширенный каталог: 50 товаров, 5 категорий (электроника, аксессуары, аудио, гейминг, умный дом)
3. Подробные описания (3–4 предложения) и расширенные характеристики (7–8 строк) у каждого товара
4. Фиксированная кнопка «Наверх» с модификатором состояния `back-to-top--visible`
5. Sticky-фильтр каталога (CSS Grid + `position: sticky`)
6. Каталог с фильтрами по категории, цене, поиску и сортировкой; счётчик найденного и пустое состояние
7. Карточка товара: рейтинг со звёздами, таблица характеристик, блок «Похожие товары» с горизонтальной прокруткой, блок «Отзывы»
8. Корзина на `localStorage`: добавление/удаление, изменение количества, подсчёт суммы, синхронизация между вкладками
9. Оформление заказа с валидацией Bootstrap и Toast-уведомлением
10. Форма обратной связи с интерактивным рейтингом (звёзды) и chip-кнопками «Как вы о нас узнали»
11. Блок часто задаваемых вопросов на `<details>` с кастомной анимацией
12. Стилизация собственных блоков по БЭМ (`product-card`, `catalog`, `related`, `reviews`, `faq`, `rating`, `chips`, `back-to-top` и др.)

## Особенности реализации
- **БЭМ поверх Bootstrap**: утилиты фреймворка (`d-flex`, `gap-3` и т.п.) не переписываются, а собственные сущности оформлены по БЭМ (`__element`, `--modifier`).
- **Данные отдельно от логики**: каталог — в `products.js`, корзина — в `cart.js`, общий рендеринг и взаимодействие — в `main.js`.
- **Валидация**: формы используют `needs-validation` + `novalidate`, паттерн телефона `+7 (999) 000-00-00`, проверку согласия на обработку данных.
- **Доступность**: ARIA-атрибуты (`aria-label`, `aria-pressed`, `aria-checked`, `aria-current`), видимый фокус, семантические теги.
- **Безопасность**: пользовательский текст (отзывы) экранируется перед вставкой в `innerHTML`.
- **Отзывы**: статические, хранятся в `products.js` (`reviewsList`); средний рейтинг и количество считаются через `getProductRating()` и используются во всех карточках.

## Как проверить
1. Откройте [GitHub Pages ссылку](https://usortr.github.io/kr2-bootstrap-shop/).
2. Оцените фиксацию шапки и работу кнопки «Наверх» при скролле.
3. Перейдите в **Каталог**: убедитесь, что фильтры «прилипают» при скролле, карточки выстроены ровно по 3 в ряд (CSS Grid), работают поиск, сортировка и фильтр по цене/категории.
4. Откройте карточку товара: проверьте рейтинг, таблицу характеристик, блок «Похожие товары» (горизонтальная прокрутка) и блок «Отзывы». У товаров без отзывов — пустое состояние.
5. Добавьте товары в корзину и перейдите в **Корзину**: проверьте изменение количества, удаление и итоговую сумму. Обновите страницу — корзина сохраняется.
6. Нажмите «Оформить заказ»: заполните форму с ошибками, чтобы увидеть валидацию Bootstrap, затем отправьте корректно — появится Toast-уведомление, корзина очистится.
7. На странице **Контакты**: раскройте FAQ, отправьте форму обратной связи с рейтингом и чипсами — появится Toast, поля сбросятся.

## Локальный запуск
Проект не требует сборки. Достаточно открыть `index.html` в браузере или запустить локальный сервер:

```bash
# например, через Python
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.
