# Контрольная работа №2: CSS-фреймворки

## Описание
Проект представляет собой учебный маркетплейс «ShopMarket», разработанный с использованием фреймворка **Bootstrap 5**. Целью работы было создание современного, отзывчивого интерфейса, максимально приближенного к UX популярных маркетплейсов (Ozon, Wildberries), с сохранением всех требований дисциплины.

## Используемые технологии
- HTML5 (семантическая разметка)
- Bootstrap 5.3 (CDN)
- Bootstrap Icons
- Vanilla JavaScript (валидация, DOM-манипуляции)
- Git, GitHub, GitHub Pages

## Структура проекта
- `index.html` — главная страница с hero-блоком и хитами продаж
- `catalog.html` — каталог с липкими фильтрами и сеткой товаров
- `product.html` — детальная карточка товара с таблицей характеристик
- `order.html` — страница оформления заказа
- `contacts.html` — контактная информация
- `css/custom.css` — точечные доработки стилей поверх Bootstrap
- `js/main.js` — логика валидации, модальных окон и кнопки "Наверх"

## Самостоятельные доработки
1. Собственная визуальная концепция
2. Расширенный каталог товаров и услуг
3. Фиксированная кнопка "наверх"
4. Sticky-фильтр каталога
5. Блок часто задаваемых вопросов
6. Блок отзывов
7. Более подробная карточка товара
8. Улучшенное модальное окно.

## Как проверить
1. Откройте [GitHub Pages ссылку](https://usortr.github.io/kr2-bootstrap-shop/).
2. Оцените фиксацию шапки и работу кнопки "Наверх" при скролле.
3. Перейдите в Каталог: убедитесь, что фильтры "прилипают", а товары выстроены ровно по 3 в ряд (`row-cols-md-3`).
4. Откройте карточку товара: проверьте наличие таблицы характеристик.
5. Нажмите "Заказать": заполните форму с ошибками, чтобы увидеть валидацию Bootstrap, затем отправьте корректно, чтобы увидеть Toast-уведомление.
